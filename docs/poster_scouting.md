# 공연 포스터를 보고 출연진 발굴하기

낮 기획실의 **포스터 발굴**에서 실제 공연 포스터를 살펴봅니다. 이미지를 누르면 원본 크기로 열 수 있고, 공연장 버튼과 이전·다음 버튼으로 다른 포스터를 고를 수 있습니다.

하단 **이 포스터 조사하기 / 2시간**을 누르면 해당 출연진이 영구 발굴됩니다. 이후 **발굴한 팀 섭외하기** 또는 팀 카드를 눌러 데모 검토·기본/넉넉한 출연 제안·공연 홍보로 이어갑니다. 발굴+데모+제안+홍보는 하루의 네 행동을 사용합니다. 여러 팀이 실린 포스터를 한 번 조사한 뒤 남은 시간에 다른 팀들에게 연속 제안하는 전략도 가능합니다.

발굴한 출연진은 다음 날에도 유지되고, 확정한 라인업은 밤의 관객·주문 빈도·공연 에너지와 티켓 정산에 반영됩니다. 기존 가상 신인 12팀과 저장 진행도는 유지됩니다.
