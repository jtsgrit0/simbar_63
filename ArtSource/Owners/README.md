# Owner selection illustrations

These portraits are project-bound raster assets for the three-owner title screen.
The game renders names, selection highlights and buttons as native Unity UI.
All illustrations use the built-in `image_gen` tool; the selected files are
copied unchanged into `Assets/Resources/SimBarArt/Owners/` and their generated
originals are retained at the default output location.

## Production notes

All three selected illustrations were generated with the built-in image generation tool in reference-based generation mode (the woman uses no reference). These are stylized game portraits, not photographs. Public source photos remain in ignored `Temp/OwnerReferences/` and are not redistributed in the runtime. The illustrated selection changes player identity only.
