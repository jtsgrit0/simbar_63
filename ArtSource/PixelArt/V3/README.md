The performance includes original clips, 120BPM phrasing, fretting/strumming IK, microphone posing and alternating drum sticks. Each frame is64×64, with four actual directions. Performance uses32frames over4seconds at8fps; social gestures use8 progressive frames. The same costumes persist when musicians leave the stage, greet people and exit. Palette encoding retains source pixel resolution and transparency; this is not an ImageGen replacement for the authored movement.
