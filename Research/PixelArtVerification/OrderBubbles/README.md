# Live customer order bubble verification

Run `uv run --with playwright python Tools/qa_native_order_bubbles.py` from the
repository root. It starts a temporary local HTTP server, loads the real core,
renderer and art in Chromium, and closes its server after testing.

The test uses actual pending orders, including both cocktails, pizza, fries and
chips. `pending-orders.png` shows item-specific icons following moving customers;
nearby cards remain separately visible. `after-service.png` shows the first
customer's icon removed after actual service. `after-show-no-orders.png` verifies
that closing removes all pending icons. These frames contain no baked balloons.

`renderer-qa.json` records the real queue and atlas source rectangles, rejected
service, automatic serving, manual preparation/serving, movement, pause,
expiration, closing and browser errors. It is regenerated by the QA script.

The additional Node suite is `Tools/test_native_order_bubbles.mjs`; the existing
`Tools/tests_pixel_presentation.mjs` validates the rest of the pixel renderer.
